### 🔨 Projekt: [NFC Member Card](https://github.com/gianlucahrt/nfc-member-card)
NFC basiertes Stammkundensystem für eine Filiale im Laufsport Fachhandel.
Stammkunden bekommen eine NFC Karte, Mitarbeitende scannen sie mit dem iPhone und
sehen sofort Kundenstufe, Rabatt, Fußtyp und Kaufhistorie.

* Serverlose Google Apps Script Web App, Google Sheets als Datenbank, 0 € Betriebskosten
* NFC Karten mit opakem Token statt personenbezogener Daten auf dem Chip
* Produktbildsuche über SerpApi mit automatischer Freistellung im Browser (Canvas)
* PIN Schutz mit Brute Force Sperre, Eingabevalidierung und Locking
* Entwickelt mit Claude als KI Entwicklungsassistent, inklusive E2E Tests mit Playwright
